# ระบบจัดตารางคิวเวร OPD ER นิติจิตเวช MCATT ICOD-R

เว็บแอปแบบไม่ต้องติดตั้ง dependencies สำหรับช่วยจัดตารางเวรนักสังคมสงเคราะห์ 8 คน โดยแยกเวรประจำรายวันออกจากเวรพิเศษ และรองรับแม่แบบอ้างอิงเดือนเมษายน 2569

## วิธีใช้

1. เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์
2. ระบุปีและเดือนที่ต้องการจัดเวร
3. กรอกชื่อเจ้าหน้าที่ 8 คน
4. กรอกวันที่ไม่พร้อมของแต่ละคน เช่น `3, 4, 18`
5. ถ้ามีภาระงานสะสมจากเดือนก่อน ให้ใส่ในช่อง `ยอดเวรเดิม`
6. ถ้ามีจำนวนครั้งที่ออก `MCATT` สะสมอยู่แล้ว ให้ใส่ในช่อง `ยอดออก MCATT เดิม`
7. กด `สร้างตารางเวร`
8. ถ้าต้องการนำไปใช้ต่อใน Excel ให้กด `ส่งออก CSV`
9. ถ้าต้องการดูเดือนอ้างอิงที่ยึดจากตารางกระดาษ ให้กด `โหลดแม่แบบเมษายน 2569`

## หลักการจัดเวรในเวอร์ชันนี้

- เวรประจำรายวันมี 2 จุดคือ `OPD`, `ER / OPD เด็ก`
- `นิติจิตเวช` เป็นคิวเตรียมพร้อมเผื่อมีเคส ไม่ถูกนับเป็นเวรบังคับทุกวัน
- แต่ละเวรหลักเป็น 1 คนต่อ 1 วัน
- `I-COD-R` ถูกวางในวันศุกร์สัปดาห์ที่ 2 และ 4 ของเดือน
- `MCATT` ไม่วางลงวันที่ตายตัว แต่สร้างเป็นคิวหมุนจากคนที่มียอดออกงานน้อยกว่า
- `Audit` จัดเป็นคู่และจะแสดงเฉพาะเดือนที่ระบบถือว่าเป็นรอบ Audit
- งาน `ตรวจความถูกต้องของงาน` จัดเป็นผู้รับผิดชอบ 1 คนต่อเดือน
- สำหรับเดือนเมษายน 2569 ระบบมีแม่แบบอ้างอิงจากตารางกระดาษ และไม่ยึด Google Calendar เป็นฐานตั้งเวร
- ถ้าวันใดเจ้าหน้าที่ไม่พอ ระบบจะแสดงช่องที่ยังจัดไม่ได้

## Publish To GitHub Pages

1. สร้าง GitHub repository ใหม่
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repo
3. ตั้ง branch หลักเป็น `main`
4. push ขึ้น GitHub
5. ไปที่ `Settings > Pages`
6. ถ้า GitHub ถามเรื่อง source ให้เลือก `GitHub Actions`
7. รอ workflow ชื่อ `Deploy GitHub Pages` ทำงานเสร็จ
8. GitHub จะสร้างลิงก์ประมาณ `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`

ไฟล์ `.github/workflows/deploy-pages.yml` ถูกเตรียมไว้แล้ว จึงไม่ต้อง build เพิ่ม เพราะโปรเจกต์นี้เป็น static web

## หมายเหตุ

เวอร์ชันนี้เป็นต้นแบบใช้งานได้ทันที และมีข้อสมมติบางส่วนที่แสดงไว้หน้าเว็บ เหมาะสำหรับเริ่มต้นเก็บเงื่อนไขงานจริงก่อนพัฒนาเพิ่ม เช่น

- วันเริ่มรอบ Audit ที่แท้จริง ถ้าไม่ได้ตรงเดือนสุดท้ายของไตรมาส

- การกำหนดคนที่ทำบางเวรได้เฉพาะเจาะจง
- ปฏิทินวันหยุดราชการ
